# Compositor Android 原版对照清单

## 对照基线

- 固定原版：Compositor for macOS 1.4.8，build 43；仓库提交 `22c7b8d`。
- 对照来源：根目录 `README.md`、`Compositor/CompositorApp.swift`、`Compositor/ContentView.swift`、`Compositor/Document/EditorSession.swift`、`Compositor/UI/` 和 `docs/project-format.md`。
- 统一需求依据为 [`android-prd.zh-CN.md`](android-prd.zh-CN.md) v0.4第21节，执行与纠偏依据为 [`android-development-plan.zh-CN.md`](android-development-plan.zh-CN.md) 第14.3～16节。此前工作副本未同步远端work，现已接入原文。此表是初步盘点，MAC-01～19菜单/参数/字段/证据细分仍属FIX-06待办。
- 当前 Android 已能只读打开 `.comp` 项目、显示图层/组列表，并生成有限的合成预览；支持图层变换、不透明度、组可见性/不透明度、像素蒙版、组蒙版和剪贴蒙版。调整层与非普通混合模式图层会跳过，图层效果未应用；绘画、撤销、图层编辑和保存尚未实现。预览不是原版完整渲染。

- [部分] 通过系统文件夹选择器读取 `.comp` 清单、层级和 PNG 文件头并展示真实图层列表；按底到顶和组内顺序合成可见像素层，处理变换、翻转、不透明度、组可见性/不透明度、像素蒙版、组蒙版和剪贴蒙版。调整层和非普通混合图层会跳过，效果未应用；没有编辑和保存。
- [ ] 完整打开、保存、另存原生 `.comp` 项目；保存期间不阻塞编辑。
- [ ] 最近项目、多项目标签、切换和关闭项目。
- [ ] 导入 PNG、JPEG、HEIC、TIFF、SVG、相机 RAW、PSD、PSB；格式转换报告能解释降级内容。
- [ ] 导出 PNG、JPEG、PDF；保留 JPEG 质量、尺寸/缩放和预览；复制合并结果。
- [ ] 图层与文件拖放；图层可跨项目复制、粘贴和拖动。
- [ ] 图层、组、顺序、可见性、不透明度、混合模式、剪贴关系和重命名。
- [部分] 项目合成预览已应用图层蒙版、组蒙版和剪贴蒙版；蒙版独立编辑、反相、模糊、羽化和变换未实现。
- [ ] 调整图层和可反复编辑的图层效果；合并向下、合并选中、合并组。
- [ ] 项目历史记录、撤销/重做；文件外部变化可发现并安全处理。

## 工具、选择与画布操作

- [ ] 工具清单：移动/变换、矩形与椭圆选框、自由/多边形套索、魔棒/对象选择、裁切、画笔/橡皮擦、污点修复、仿制图章、模糊、渐变、形状、文字、吸管、抓手、缩放。
- [ ] 画笔大小/硬度/不透明度/平滑；绘制、擦除、直线和触控笔压力。
- [ ] 变换：移动、缩放、旋转、翻转、自由扭曲；多层/组同时变换、数值输入和吸附。
- [ ] 选区：新增/相加/相减、移动边界、选区像素移动/复制、反选/取消、载入图层像素或蒙版。
- [ ] 选区扩展、收缩、羽化、主体选择、颜色范围和内容识别填充/扩展画布。
- [ ] 形状保持可编辑；文字段落框可输入、移动、缩放并作为剪贴内容。
- [ ] 画布旋转/翻转；裁切比例与对称裁切；画布尺寸、图像尺寸、修边。
- [ ] 标尺、拖拽参考线、网格与细分；吸附开关和吸附目标；锁定/清除参考线。
- [ ] 导航器从 300% 显示；像素网格从 800% 显示；适合窗口、实际像素和连续缩放。
- [ ] 取色器、完整颜色面板、前景/背景色及填充。

## 调整、滤镜与输入方式

- [ ] Camera Raw：光线、颜色、曲线、颜色混合、分级、细节、光学、几何。
- [ ] 调整：曲线、色阶/自动色阶、色相/饱和度、曝光、渐变映射、颗粒、黑白、色彩平衡、反相。
- [ ] 滤镜：高斯/动态模糊、噪点、暗角、Bloom/Glow、抖色、扫描线、色调对比、镜头校正、移除背景。
- [ ] 滤镜实时预览；选区存在时仅预览/作用于选区；上次滤镜保留参数并可重做。
- [ ] 原版快捷键、可重映射快捷键、命令搜索；文本输入时不抢走文本编辑快捷键。
- [ ] 数值标签拖动调节；触摸、触控笔和鼠标操作均有明确反馈。
- [ ] 大图的内存限制、快速预览和缩小采样质量；失败时提示真实原因并保护原文件。

## 验收记录

每项需分别记录：代码完成、自动检查/构建、模拟器或真机验收。三者不互相替代。真机验收至少覆盖平板横竖屏、折叠屏内屏、触控笔（若设备支持）、保存后重开和代表性 PSD/PSB。没有对应设备时标记待测，不写成通过。
