# Android 版 `.comp` 文件格式移植笔记

## 已核对的原版规则

来源是当前仓库的 `docs/project-format.md`、`Compositor/IO/ProjectStore.swift`、`Compositor/Document/LayerTransform.swift`、`Compositor/Document/DocumentLimits.swift` 和 `Compositor/Document/EditorSession+Projects.swift`。

- `.comp` 是**目录包**，不是单个压缩文件。根目录有 `manifest.json` 和 `images/`；可选的 `QuickLook/Preview.jpg` 只供 Mac 快速预览。
- 新保存写格式版本 11；原版读取版本 1–11。色彩空间固定为 `sRGB`。顶层记录文档 UUID、像素宽高、分辨率、活动图层、图层数组和可选参考线。
- 图层数组按底到顶排列。每项包括 UUID、名称、可见状态、变换、像素文件名，以及可选父组、不透明度、混合模式、蒙版、剪贴关系、调整、形状、效果和文本字段。
- 像素层文件名必须是 `<UUID>.png`；蒙版文件名必须是 `<UUID>.mask.png`，都位于 `images/`。空白层、组和调整层没有像素文件。PNG 是嵌入资产，原文件移动或删除不影响项目。
- 变换用文档像素坐标记录未旋转矩形：`origin`、`size`、顺时针角度、水平/垂直翻转和采样方式。旋转围绕矩形中心。
- 分辨率是可选字段；旧项目没有时按 72 像素/英寸读取。画布打开后适配窗口；历史记录、当前缩放和组折叠状态不写进项目。
- 保存前必须校验完整项目，再以临时完整包替换旧项目；图片/元数据不完整时不能破坏当前文档或原文件。

## 版本增加的内容

| 版本 | 数据变化 |
|---|---|
| 1 | 基础画布、像素层和变换 |
| 2 | 组层级和父图层 ID |
| 3 | 图层不透明度与混合模式 |
| 4 | 普通图层栅格蒙版 |
| 5 | 剪贴/实时蒙版链接 |
| 6 | 组蒙版 |
| 7 | 调整图层 |
| 8 | 组不透明度、参考线 |
| 9 | 高斯模糊、动态模糊、噪点调整图层 |
| 10 | 文字的混合颜色段 |
| 11 | 文字的混合字体段 |

此外还有可选字段：分离蒙版的独立变换、形状样式、可编辑文字、六类图层效果。它们保存时也必须保留，不能只复制每层 PNG。

## 校验边界

- 原版代码要求格式名正确、版本在 1–11、色彩空间为 sRGB、尺寸为正且每边不超过 30,000 像素、图层不超过 10,000 项。
- `manifest.json` 最大 4 MiB；每个编码资产最大 512 MiB。UUID 不得重复；组树、蒙版引用、层变换、字段范围和对应版本都要校验。
- `ProjectStore.swift` 的每边限制和动态总像素预算是实际代码规则。格式文档仍写着固定 100 百万源像素，但 `DocumentLimits.swift` 已改成随设备内存变化、最低 200 百万且最高 800 百万像素；Android 不能照抄文档中的旧数字，需按 Android 可用内存另定安全预算并避免 OOM。
- 读取时拒绝符号链接/越界路径、损坏 PNG、缺失资产和不支持版本；只有整个包有效后才能替换当前项目。

## Android 实现要求

1. 用 Storage Access Framework 读取和创建目录包，让用户明确选择位置；不能把 Android 私有缓存当作“已保存”。
2. 第一阶段的数据层要保留原始 manifest 中暂未实现的字段与对应资产。没有对应编辑能力时，不能静默丢弃字段后覆盖用户项目。
3. 用临时项目目录完整写入并验证，再提交替换；若目标文档提供器不支持可靠重命名/替换，必须保留旧包并提示用户选择可安全保存的位置。
4. 分别测试版本 1、11、组/蒙版/调整/文字项目、缺失文件、坏 PNG、超限尺寸、重复 UUID、恶意路径和保存中断。没有 Mac/真机时，这些仍是设备/互操作待测项。

## 当前实现状态

- 已实现只读的 SAF 项目目录读取：检查格式名/版本、画布尺寸、图层基础字段、全部原版混合模式、UUID/父组/剪贴链接、参考线，以及被引用文件是否存在和 PNG 头信息。
- 原始 `JSONObject` 会连同已识别信息保留在内存中，暂未实现的字段不会在读取阶段丢弃。
- 项目打开时会检查 PNG 文件头；渲染预览时按需解码可见图层、蒙版和剪贴来源，并限制预览图最长边与缓存。打开项目时不会预先逐个完整解码所有 PNG 或验证所有资产的 CRC。
- 已实现只读有限画布合成：支持普通像素层及其变换、不透明度、像素蒙版、所属组蒙版和剪贴蒙版。单层预览显示原始 PNG，不应用蒙版。调整层、非普通混合模式和效果仍未完整渲染；没有修改或保存功能。
- 用户已在小米 18 Fold 上打开仓库制作的 `.comp` 样例并提供截图；常规图层预览、蒙版和剪贴蒙版的画面符合样例预期。该样例不是 Mac 导出的项目，原版互操作仍待验证。
- `clean lintDebug testDebugUnitTest assembleDebug` 已成功；最新一次 10 项 JVM 单元测试通过，Lint 0 错误、3 条 SDK/Gradle 升级建议。云端 `adb devices -l` 为空，用户手动检查了样例画面与转屏，完整设备验收未完成。本次依赖准备阻塞与现有报告见[验证记录](../android/validation/README.zh-CN.md)。

后续按[主计划](android-development-plan.zh-CN.md)第14.3节，从失败打开保护开始，补齐基础混合并贯通真实画布编辑、撤销及安全保存。调整层和图层效果继续按最终对齐队列推进；当前只读预览不能代替这些能力。
