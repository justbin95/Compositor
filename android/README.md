The current app can open a native `.comp` project folder or a `.comp.zip` archive through Android's system picker. ZIPs may contain one `<name>.comp/` folder or put `manifest.json` and `images/` directly at the archive root. The importer checks paths, entry types, sizes, CRCs, the manifest, layer hierarchy, and referenced PNGs, then extracts into app-private cache. A failed open leaves the currently selected project intact. The selected source folder or archive is not modified. The app then renders a bounded-resolution preview from visible pixel layers in native bottom-to-top order. It applies layer transforms, opacity, group visibility and opacity, raster masks, group masks, and clipping masks. Preview Bitmap limits and the mask cache are derived from current process and system memory headroom. Selecting a row previews that layer's source image by itself, without masks.

This is a partial renderer. Adjustments and unsupported blend layers are skipped (Normal, Darken, Multiply, Lighten, Screen, Overlay and Difference are supported), and layer effects are not applied; the screen reports these limits. For a visible Normal pixel layer without effects, Brush mode provides a temporary black, hard, 32 px brush. Touch coordinates are mapped from the canvas through the layer transform into source PNG pixels. The core loads 256×256 source chunks on demand, interpolates a continuous stroke, and composites into premultiplied RGBA8 memory. Releasing the pointer commits the in-memory stroke; cancellation or loss of window focus rolls back the active stroke. Adding a second pointer rolls back the unfinished one-finger stroke and locks the rest of that gesture to navigation, so a pinch does not leave a brush mark. The user confirmed this pinch behavior on a Xiaomi 18 Fold. Undo and Redo buttons operate on the selected layer's temporary brush history, capped at 20 strokes and a per-layer snapshot byte budget; accepting a new stroke after undo clears that layer's redo branch, and the oldest undo entries are discarded as needed. The user also reported that ordinary strokes, undo/redo, the redo branch, and per-layer history switching worked on the Fold. **Export Layer PNG** creates a separate source-pixel PNG for the selected layer. **Save Copy (.comp.zip)** writes an independent project package with the original manifest and image assets, replacing any layer PNG that has committed temporary brush edits. The ZIP importer reopens that package from app-private temporary storage; the selected source remains unchanged. Selected ZIP roundtrips and exports are reported PASS in the local ADB report; image imports fail and export completeness needs a repair. See the latest results below. Mac interoperability remains pending.

**Export Canvas** writes an exact canvas-size composite PNG or JPEG, including committed brush edits, transforms, opacity, raster/group/clipping masks, and the seven supported blend modes. PNG keeps transparency; JPEG fills transparency with white and offers 75/90/100 quality. Progress and Cancel Export are available. Export fails explicitly for visible unsupported adjustments/effects/blend modes or insufficient measured memory; it never substitutes a sampled preview. The current compositor uses full-resolution Bitmap surfaces with conservative admission limits; large-image tiled composition, export DPI metadata, JPEG output previews and sharing remain pending. Cancellation/failure attempts to delete the incomplete SAF document and reports cleanup failure. Configuration changes cancel a running canvas export and retain its completion state until cleanup finishes.

**Open Project → Import PNG or JPEG as New Project** copies the input into private storage, checks format/dimensions/memory before full decode, applies image orientation with ImageDecoder, converts to RGBA8/sRGB, and creates a one-layer project with a normalized PNG asset. The original image is unchanged. Save Copy embeds the normalized image so the resulting ZIP is independent of the photo. This does not yet append layers to an existing project or offer resized imports; oversized inputs are rejected. Cancel Open aborts a pending load and preserves the current project. When brush edits exist, choosing another document first shows a discard warning. **Composite** returns to the composite preview including committed brush edits; it remains a sampled preview, not the exact-size export. These entries are implemented; local ADB found a manifest error that prevents PNG/JPEG import. The repair is pending.

The canvas still supports pan, pinch zoom, and double-tap reset in Navigate mode. `editor-core` contains coordinate mapping, sparse editable chunks, stroke transactions, reversible before/after patches, and a bounded per-layer stroke history. The Android buttons expose undo and redo for brush strokes only; transforms and layer operations are not editable yet. The NDK ARM64 library includes the portable `BrushPixels.c` algorithms and a direct-ByteBuffer alpha-bounds JNI entry. JNI output and runtime memory limits still need fixed-data and device checks. The initial layout adapts between a portrait stack and a landscape split workspace; project selection and orientation state recovery have been manually checked on a Xiaomi 18 Fold inner display.

## Build a debug APK

The current toolchain uses JDK 21, Gradle 9.6.0, Android Gradle Plugin 9.4.0, Android SDK Platform 36 with Build Tools 36.0.0, NDK 27.2.12479018, and CMake 3.22.1. Install those components and use the checked-in Gradle Wrapper. The Debug package includes only `arm64-v8a`. Set `ANDROID_HOME` to the SDK directory and run:

```sh
./gradlew assembleDebug
```

The APK is written to `app/build/outputs/apk/debug/app-debug.apk`.

To keep debug APK signatures identical across build environments, provide the same keystore outside the repository through `COMPOSITOR_DEBUG_KEYSTORE`, `COMPOSITOR_DEBUG_KEYSTORE_PASSWORD`, `COMPOSITOR_DEBUG_KEY_ALIAS`, and `COMPOSITOR_DEBUG_KEY_PASSWORD`. Set all four variables together. If none are set, Gradle uses its per-user default debug keystore, which can differ between machines. Never commit the keystore or passwords.

Choose the folder that directly contains `manifest.json` and `images/`, or choose a `.comp.zip` archive. ZIP extraction uses app-private cache; the source project is not modified.

`samples/Compositor-Android-Demo.zip` contains a small six-record `.comp` folder with five pixel layers and one group. `samples/Compositor-Android-Mask-Demo.zip` exercises raster masks, a group mask, and a clipping mask whose source layer is hidden. `samples/Compositor-Android-Blend-Demo.comp.zip` contains an eight-layer project that displays the seven supported blend modes for visual comparison. These were created for Android preview testing from the format described in the [official project-writing guide](https://github.com/robbietilton/Compositor/blob/main/docs/writing-comp-files.md); none is a project or artwork published by the Compositor author. The mask sample's expected composite and the blend sample's seven mode previews have been visually confirmed by the user on a Xiaomi 18 Fold. On Android, choose an extracted `.comp` folder or a supported `.comp.zip` archive.

To install it on a connected Android device, install Android Platform Tools and run:

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Latest internal recovery stage (2026-10-12)

RECOVERY06 keeps internal recovery separate from Save Copy. Every 30 seconds, after supported long operations and when leaving the foreground, the editor attempts to capture completed edits within a measured snapshot budget. An active stroke is not captured. Frozen chunk payloads allow later editing while a background task writes a ZIP, syncs its file descriptor, reopens it through the production importer, atomically publishes a new generation and syncs its directory. Earlier valid generations are retained. Revision and session identity prevent an older save from acknowledging newer edits or a reopened document.

Recovery Copies is available in Open and the tool row. It lists timestamps, project names and sizes, offers restoration with an unsaved-edits warning, and confirms deletion of an individual internal copy. The latest two generations of the three most recently recovered projects are retained. Undo history is not restored. Uninstalling or clearing app data may remove these internal copies; use Save Copy for a project file you want to keep.

See [checks and artifact identity](validation/recovery06-20261012.zh-CN.md) and [deferred device checklist](validation/recovery06-device-checklist.zh-CN.md). The user has deferred device testing: this stage makes no ADB calls or installation. Windows fault injection does not validate Android directory durability, process death, real low storage or the device UI. External folder saving, incremental recovery asset reuse, full-image tiled composition and final macOS parity remain pending.
