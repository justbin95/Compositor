# Android `.comp` 手动测试样例

- `Compositor-Android-Demo.zip`：普通多图层项目，用于查看图层顺序和单层预览。
- `Compositor-Android-Mask-Demo.zip`：包含像素蒙版、组蒙版和剪贴蒙版。项目合成预览应显示红色从左向右渐隐、绿色内容在画面上部显示并向下渐隐，背景为深蓝色；顶部还有一个隐藏的透明圆形来源，黄色剪贴层应仍显示为半透明圆形。用户在小米 18 Fold 上提供的截图确认以上效果符合预期。

两个项目都是仓库内按 Compositor 格式制作的测试样例，不是官方作品。解压 ZIP 后，在应用中选择名称以 `.comp` 结尾的项目文件夹。
