# Android `.comp` 手动测试样例

- `Compositor-Android-Demo.zip`：普通多图层项目，用于查看图层顺序和单层预览。
- `Compositor-Android-Mask-Demo.zip`：包含像素蒙版、组蒙版和剪贴蒙版。项目合成预览应显示红色从左向右渐隐、绿色内容在画面上部显示并向下渐隐，背景为深蓝色；顶部还有一个隐藏的透明圆形来源，黄色剪贴层应仍显示为半透明圆形。用户在小米 18 Fold 上提供的截图确认以上效果符合预期。

两个项目都是仓库内按 Compositor 格式制作的测试样例，不是官方作品。解压 ZIP 后，在应用中选择名称以 `.comp` 结尾的项目文件夹。

## FIX-01：打开失败时保留当前项目

- [FIX-01 手动验证包](FIX-01-Manual-Test.zip)：包含有效基准项目，以及缺失 PNG、损坏 manifest、不支持版本和无法解码 PNG 四种失败案例。
- 解压后先打开 `01-有效基准.comp`，再逐个尝试其余项目。每次失败后，确认有效项目仍显示、当前图层选择和预览保留，并且图层列表仍可操作；最后再次打开有效项目确认切换成功。
- PNG 案例保留了有效签名和 IHDR 头，截断在图像数据前，用于触发完整解码失败。详细步骤见压缩包内的 `README.zh-CN.md`。
